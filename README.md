# mac-quicknotes · 7 天 AI 辅助学习计划

> 目标：一周内做出一个本地优先、可同步、数据可靠的 macOS 速记应用。
> 技术栈：Swift / SwiftUI + SQLite（GRDB.swift）+ WebDAV。
> 节奏：每天 2–3 小时。**P0 是本周必须完成的交付，P1 有余力再做，P2 留到之后。**

## 使用说明

1. 每天先读「学」和「验收」，再动手；验收不过不进入下一天。
2. 每段「AI 提示词」可直接复制到对话里，把上下文补成你自己的代码再问。
3. 勾选框用于记录进度，每天结束填 5 行复盘。
4. 核心原则：**先写清楚验收标准，再让 AI 写代码。**

## 技术选型与数据架构

- **数据库层**：GRDB.swift（对 Swift 并发/actor 更友好），`DatabaseQueue` + `Migrator`，WAL 模式。
- **表设计**：`notes`、`tags`、`note_tags`、`attachments`、`versions`、`sync_state`、`fts_notes`（FTS5 虚拟表）。
- **同步单元**：远端按「每篇笔记一个 `.md` + 附件目录」存储，SQLite 作本地主库与索引。远端文件人眼可读，冲突时可按文件找回。
- **同步状态**：`sync_state` 记录 `remote_etag`、`local_hash`、`remote_mtime`、`last_synced_at`、`dirty`。
- **凭据**：只进 Keychain，不写 plist，不进导出文件。
- **数据目录**：`~/Library/Application Support/QuickNotes`，Time Machine 默认备份。

## AI 协作的六条心法

1. **Spec 先行**：先写验收标准，再让 AI 写代码，否则它会给你「看起来对」的东西。
2. **小步提问**：一次只解决一个问题，追问「为什么」，让它解释取舍而不是只给答案。
3. **报错贴原文**：贴完整错误 + 最小复现，不要只说「跑不起来」。
4. **AI 当 reviewer**：每个模块完成，让它找边界条件和内存/并发问题。
5. **测试自己写关键路径**：AI 擅长造数据和用例，但断言必须你自己确认。
6. **每天收尾 5 行复盘**：今天学会什么、卡在哪、AI 帮了什么、明天先做什么。

## 三个提前避的坑

1. **中文 FTS5**：系统 SQLite 的 `unicode61` 几乎不切中文；`trigram` tokenizer 要先确认系统库版本，必要时自编译静态链接。
2. **同步节流**：编辑后 debounce 2–5 秒再入队并批量 PUT，别一次请求一个字。
3. **沙盒路径**：数据放 `Application Support/QuickNotes`，Time Machine 默认会备份；用户手动导出走安全作用域书签。
